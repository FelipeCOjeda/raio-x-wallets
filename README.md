# Raio-X das Wallets

Comparativo aberto de hardware wallets, hot wallets e onde comprar cripto.
Todo incidente de segurança listado tem fonte.

## Editar os dados
Tudo fica no topo do `<script>` em `index.html`:
- `INC` — incidentes (tipo `roubo` ou `vazamento`, data, resumo, fontes)
- `CATS` — categorias, critérios e itens
- Células: `"s"` sim · `"n"` não · `"p"` parcial · `"u"` não verificado · `["s","observação"]`
- Patrocinado: adicione `patrocinado:true` no item

## Publicar no GitHub Pages
Settings → Pages → Source: branch `main`, pasta `/ (root)`.
